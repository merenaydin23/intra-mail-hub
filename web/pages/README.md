# Web HTML Sayfaları

Bu klasör, uygulamanın farklı bölümlerinin arayüz (HTML) şablonlarını barındırır. CSS dosyaları ve JavaScript modülleri buradaki elementlere bağlanır.

## 📂 Dizin İçeriği

- **`/admin`**: Yönetim ekranlarını barındırır (örn: `yonetim.html`, `yonetim_personel.html`). Sadece yetkili yöneticilerin girebildiği sayfalardır.
- **`/portals`**: Farklı roller için ana ekran girişlerini barındırır (örn: `bolge.html` bölge yetkilileri için, `fabrika.html` fabrika yetkilileri için, `calisan.html` standart çalışanlar için).
- **`repair.html` / `setup.html`**: Kurulum ve acil onarım ekranları.
