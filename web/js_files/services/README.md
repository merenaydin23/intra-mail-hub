# Web Servis Modülleri

Bu klasör, projenin harici bağlantılarını (Firebase servisleri, 3. parti API'ler, Yapay Zeka entegrasyonu vb.) kontrol eden özel fonksiyonları içerir. İş mantığını arayüz kodlarından ayırmak ve modülerliği artırmak için kullanılmıştır.

## 🤖 Servisler
- **`ai-service.js`**: Gemini/OpenAI benzeri yapay zeka entegrasyonlarını yönetir. Gelen veya giden uzun metinlerin özetlenmesi veya analiz edilmesi gibi işlemlerde kullanılır.
