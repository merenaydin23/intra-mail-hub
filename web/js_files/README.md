# Web JavaScript Modülleri

Bu klasör, Web uygulamasının beyni niteliğindedir. Sayfaların etkileşimleri, veritabanı işlemleri ve arayüz güncellemeleri buradaki dosyalar üzerinden sağlanır.

## 📄 Önemli Dosyalar

- **`main.js`**: Uygulamanın ana giriş noktasıdır. Giriş/çıkış kontrollerini yapar ve temel ortam değişkenlerini ayarlar.
- **`inbox.js`**: Gelen kutusu mantığını içerir (Mesajları listeleme, okuma, yeni mesaj gönderme vb.).
- **`admin.js`**: Yönetici panelindeki kullanıcı, yetki ve sistem ayarları gibi kritik fonksiyonların yürütüldüğü dosyadır.
- **`page_guard.js`**: Sayfa erişim izinlerini denetler (Kullanıcı giriş yapmamışsa veya yetkisi yoksa sayfalara erişimi engeller).

## 📂 Alt Klasörler
- **`/services`**: Harici API'lerle ve Firebase ile iletişim kuran soyutlanmış servis modülleri yer alır (Örn: `ai-service.js`).
- **`/firebase`**: Firebase config ve başlatma ayarları.
