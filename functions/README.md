# Cloud Functions

Burası Firebase Cloud Functions kodlarını içerir. İstemci tarafında (web veya mobil) yapılması güvenli veya performanslı olmayan işlemler (örn. yetki atama, yoğun veri analizi, güvenli bildirim gönderimi) arka planda sunucu ortamında Node.js üzerinde çalıştırılır.
